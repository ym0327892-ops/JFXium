# JFXium 最佳实践

> 本文档汇总 JFXium 框架的核心使用规范——红线、API 选型、防御性编程、i18n、主题、消息反馈。
> 以下规范为框架的硬性约束，违反将导致组件样式失效或主题切换异常。

## 0. 11 条致命红线（速查）

> ⚠️ **违反任何一条直接打回重写**。

| # | 红线 | 正确做法 |
|---|------|----------|
| 1 | `setStyle()` 写颜色 / px | 走 `styleClass` + LESS（`JfxStyles.XXX` + `components/_xxx.less`） |
| 2 | CSS `box-shadow` | 用 `-fx-effect: dropshadow(...)` |
| 3 | CSS `:active` / `:focus` | 用 `:pressed`（`:armed`）/ `:focused` |
| 4 | `-fx-transition` 用于交互状态 | 直接定义状态颜色（`:hover` / `:pressed` 切换） |
| 5 | 容器吞 padding | 组合控件容器 `-fx-padding: 0`，下放到子节点 |
| 6 | `@border-radius-full`(9999px) 用于未钳制尺寸节点 | track / 进度条用 `@border-radius-md` |

| 11 | 业务代码 `new` 原生 JavaFX 控件（Label/Button/TextField/...） | 统一走 `XxxAnt.create(...)` 链式 API |

## 1. Builder 模式 + 链式 API

**所有组件和布局都使用 Builder 模式，避免手动 `new` 和 setter 调用：**

```java
// ✅ 推荐：使用 Builder
// Size 是统一枚举 org.openkawu.jfxium.core.token.Size（无 ButtonAnt.Size 内部枚举）
Button btn = ButtonAnt.create("保存")
    .type(ButtonAnt.Type.PRIMARY)
    .size(Size.LARGE)
    .rounded()
    .onClick(e -> save())
    .build();

VBox layout = VBoxAnt.create()
    .spacing(16)
    .padding(24)
    .children(input, btn)
    .build();

// ❌ 反模式：手动 new + setter（违反红线 #11）
VBox layout = new VBox(16);
layout.setPadding(new Insets(24));
layout.getChildren().addAll(input, btn);
```

**为什么推荐 Builder？**
- 链式调用更简洁，可读性高
- 统一的 API 风格（`XxxBuilder.create()` / `XxxAnt.create()`）
- 支持 `.styleClass()` / `.style()` 钩子
- 避免遗漏必要的设置（如 styleClass 注入）
- **推荐 `.bindValue(Property)` 代替手动持有控件引用取/设值**（M19.51）

```java
// ✅ 推荐：用 bindValue，不持有控件引用
StringProperty name = new SimpleStringProperty("");
InputAnt.create().placeholder("姓名").bindValue(name).build();
// name.get() 随时取值，name.set(...) 设值，name.addListener(...) 监听

// ❌ 反模式：持有控件引用取值
TextField field = InputAnt.create().placeholder("...").build();
String value = field.getText();  // 需要持有 field 引用
```

## 2. 防御性编程（必读）

外部输入是「不可信的」。所有 Builder setter 必须守卫异常输入，避免 NPE / IllegalArgument 穿透到 `build()`。

### 2.1 输入校验矩阵

| 输入类型 | 必校验 | 不合法时 |
|----------|--------|----------|
| **枚举参数** | `null` → 语义默认值（如 `Type.DEFAULT`） | 永远不让 NPE 抵达 `switch` |
| **文本参数**（title / text / placeholder） | `null` → `""` 空串 | 走 `TextUtils.safeText(input, "")` |
| **数值参数**（gap / size / count / padding） | NaN / Infinity / 负数 → 钳到安全值（0 或 min） | `TextUtils.safeNonNegative(val, 0)` |
| **百分比参数**（leftRatio / progress / opacity） | 钳到 `[0, 100]` 或 `[0, 1]` | `NumericUtils.clamp(...)` |
| **回调参数**（onClick / onClose / onChange） | `null` → 不绑 handler | 允许 null，业务侧"不调即不触发" |
| **`Node...` / 集合参数** | 允许空数组 / 空集合 | 逐个 `Objects.nonNull(n)` 过滤 |
| **`maxSize` 配 `minSize`** | 确保 `max ≥ min` | 不合法时 max = min |

### 2.2 工具收口

```java
import org.openkawu.jfxium.core.util.TextUtils;
import org.openkawu.jfxium.core.util.NumericUtils;
import org.openkawu.jfxium.core.util.Callbacks;

// 文本：null → ""
String safeTitle = TextUtils.safeText(title, "");
String safeText  = TextUtils.safeText(title);              // null → ""

// 数值：负数 → 默认值
double gap      = TextUtils.safeNonNegative(rawGap, 0);
double width    = TextUtils.safePositive(rawWidth, 240);
int    count    = TextUtils.ensureAtLeastOne(rawCount);    // < 1 → 1

// 百分比：[10, 90] 钳制
double ratio    = NumericUtils.clamp(leftRatio, 10, 90, 60);

// 集合：null 安全 + 过滤 null 元素
TextUtils.addNonNull(list, nodes);                          // null 入参跳过
```

### 2.3 三个 build() 契约

```java
// ✅ 契约 1：build() 必须幂等 —— 重复调用不累积
TableView<User> t1 = TableAnt.<User>create().column(...).build();
TableView<User> t2 = TableAnt.<User>create().column(...).build();
// t1 == t2（同一配置产生等价结果），且 build 不会偷偷 add 节点

// ✅ 契约 2：build() 返回类型诚实 —— 持久节点返回 Node，弹窗返回 Result wrapper
BorderPane page = PageTemplate.create().title("...").build();        // 持久节点
DrawerAnt.DrawerResult dr = DrawerAnt.create().build();               // 弹窗
dr.open(trigger);                                                       // 必须 .open 才显示

// ✅ 契约 3：FX 线程边界 —— snapshot() / Canvas / scene-graph 操作必须 Platform.isFxApplicationThread()
if (!Platform.isFxApplicationThread()) {
    Platform.runLater(() -> updateSnapshot());
}
```

### 2.4 红线违规示例

```java
// ❌ 违反红线 #1：setStyle 写颜色 / px

// ✅ 正确：走 LabelAnt + styleClass + LESS

// LESS: .jfx-page-template-title { -fx-font-size: 28px; -fx-font-weight: 700; }
```

```java

// ✅ 正确：走 LabelAnt

```

## 3. i18n 懒解析（避免锁死 Locale）

> 默认 Locale：`zh_CN`。所有用户可见文案必须走 `Messages.get(...)`，**字段初始化时不能锁死**。

### 3.1 错误 vs 正确模式

```java
// ❌ 错误：字段初始化时锁死 Locale（class-load 时确定，永不切换）
private String placeholder = Messages.get("treeselect.placeholder");

// ✅ 正确：null 占位 + build() 中懒解析
private String placeholder = null;
// build():
String effective = placeholder != null ? placeholder : Messages.get("treeselect.placeholder");
```

### 3.2 持久组件（不是一次性弹窗）

需要监听 `Messages.localeProperty()` 让用户切语言时实时更新：

```java
// Modal / Notification 这种一次性弹窗不需要监听（弹完即销毁）
// 持久组件（Form / TreeSelect / CodeBlock / Upload / Transfer / Popconfirm / Empty）必须监听
Messages.localeProperty().addListener((obs, oldL, newL) -> {
    rebuildTextNodes();   // 重新从 Messages.get(...) 取文案
});
```

### 3.3 key 命名规范

```properties
# i18n/messages.properties
treeselect.placeholder=请选择...
codeblock.copy=复制
upload.button=点击上传
empty.description=暂无数据
modal.confirm=确认
```

格式：`<组件>.<元素>`，全小写，下划线分隔。`MessageFormat` 占位符用 `{0}` / `{1}`。

## 4. 页面骨架继承式写法（M19.36）

> JFXium 在 `component/layout/` 下提供 **14 个继承式布局容器**——一个类同时支持 **「直接继承」+「工厂链式」+「Builder build()」** 三种用法。

### 4.1 容器清单

| 原生容器 | 继承式 *Ant | 何时用 |
|---|---|---|
| VBox | **VBoxAnt** | 垂直布局，最常用 |
| HBox | **HBoxAnt** | 水平布局，最常用 |
| BorderPane | **BorderPaneAnt** | 五区位骨架（top/right/bottom/left/center）|
| StackPane | **StackPaneAnt** | 子节点叠层（徽标 / loading 遮罩 / 浮层）|
| FlowPane | **FlowPaneAnt** | 流式布局自动换行（标签云）|
| ScrollPane | **ScrollPaneAnt** | 简单滚动（裸 ScrollPane 双工厂）|
| SplitPane | **SplitPaneAnt** | 可拖拽分割窗格（IDE 风格分屏）|
| TilePane | **TilePaneAnt** | 平铺网格（缩略图 / 图标面板）|
| AnchorPane | **AnchorPaneAnt** | 绝对定位（弹窗覆盖 / 仪表盘）|
| TextFlow | **TextFlowAnt** | 富文本流式排版（多段拼接 + 图文混排）|

外加增强型组件：`HBarAnt` / `VBarAnt`（`composite` 包，带 left/center/right 分段 + 边框分隔线）、`GridAnt`（24 栅格响应式，二维网格布局统一用它）、`Spacers`（`core.util`，弹性占位 + 固定尺寸）。

### 4.2 三种用法

```java
// 用法 1：直接 new + 链式（最简）
VBoxAnt root = new VBoxAnt().spacing(16).children(label, btn);

// 用法 2：工厂 + 链式（跟 *Ant 风格统一，build() 可选）
VBoxAnt root = VBoxAnt.create()
    .spacing(16)
    .background(Background.LAYOUT)
    .children(label, btn);
// 或显式 build：
VBoxAnt root = VBoxAnt.create().spacing(16).children(label, btn).build();

// 用法 3：业务继承（页面骨架基类，最常见的业务写法）
public class HomeView extends VBoxAnt {
    public HomeView(String currentUser) {
        spacing(16);
        padding(24);
        background(Background.LAYOUT);
        children(
            LabelAnt.create("欢迎，" + currentUser),
            buildDashboard()
        );
    }

    private Node buildDashboard() {
        return DashboardTemplate.create()
            .stat(IconAnt.Path.USERS, "总用户", "1,234", "↑ 12.5%", true)
            .build();
    }
}

// 业务侧使用：直接当 VBox 添加进容器
container.getChildren().add(new HomeView("alice"));
```

### 4.3 三类页面的标准写法

不同生命周期的页面用不同骨架：

```java
// === 类型 1：路由内的页（首页 / 列表 / 详情）—— extends VBoxAnt / BorderPaneAnt ===
public class HomeView extends VBoxAnt {
    public HomeView(String currentUser) {
        spacing(16).padding(24).background(Background.LAYOUT);
        children(buildHeader(currentUser), buildContent());
    }
}

// === 类型 2：登录窗口 / 配置窗口（独立 Stage）—— 持有 Stage 字段 ===
public class LoginView {
    private final Stage stage = new Stage();
    private final Consumer<String> onLogin;

    public LoginView(Consumer<String> onLogin) { this.onLogin = onLogin; }

    public void show() {
        BorderPane content = LoginTemplate.create()
            .brandName("我的应用")
            .onSubmit((u, p) -> onLogin.accept(u))
            .build();

        Scene scene = new Scene(content, 760, 520);
        ThemeManager.getInstance().applyTheme(new LightTheme());
        ThemeManager.getInstance().registerScene(scene);

        stage.setScene(scene);
        stage.setTitle("登录");
        WindowManager.getDefault().register(stage);
        stage.show();
    }

    public void close() { stage.close(); }
}

// === 类型 3：第二窗口（配置 / 设置）—— extends BorderPaneAnt + 持有 Stage ===
public class SettingsView extends BorderPaneAnt {
    private final Stage stage = new Stage();

    public SettingsView() {
        center(buildSettingsForm());
        bottom(buildFooter());
        background(Background.LAYOUT);
    }

    public void show(Stage owner) {
        Scene scene = new Scene(this, 600, 500);
        ThemeManager.getInstance().registerScene(scene);

        stage.setScene(scene);
        stage.setTitle("设置");
        stage.initOwner(owner);
        WindowManager.getDefault().register(stage);
        stage.show();
    }

    private HBox buildFooter() {
        ButtonAnt cancel = ButtonAnt.create("取消").onClick(e -> stage.close()).build();
        ButtonAnt save = ButtonAnt.create("保存").type(ButtonAnt.Type.PRIMARY)
            .onClick(e -> { saveSettings(); stage.close(); }).build();
        return HBarAnt.create().right(cancel, save).build();  // ← 旧 BarAnt 已废弃
    }

    private void saveSettings() {
        EventBus.getDefault().publish(new SettingsChanged());
    }
}
```

| 类型 | 写法 | 持有 Stage | 入口方法 | 何时用 |
|---|---|---|---|---|
| **路由内的页** | `extends VBoxAnt / BorderPaneAnt` | ❌ | 构造函数 | 首页 / 列表 / 表单 / 详情 |
| **独立窗口** | 持有 Stage 字段，不继承容器 | ✅ | `show()` | 登录 / 注册 / 关于 |
| **第二窗口** | `extends BorderPaneAnt` + 持有 Stage | ✅ | `show(owner)` | 配置 / 设置 / 用户编辑 |

### 4.4 BarAnt → HBarAnt / VBarAnt 迁移

> `BarAnt` 已废弃为 `HBarAnt`（横向 left/center/right 三段式 + borderBottom/Top 分割线）和 `VBarAnt`（纵向 top/center/bottom + borderLeft/Right 分割线）。

```java
// ❌ 旧：BarAnt 单类（已删除）
BarAnt bar = BarAnt.create().right(cancel, save).build();

// ✅ 新：HBarAnt（横向）
HBarAnt bar = HBarAnt.create()
    .left(breadcrumb)
    .center(searchBox)
    .right(refreshBtn, addBtn)
    .gap(12)
    .borderBottom(true)
    .build();

// ✅ 新：VBarAnt（纵向）
VBarAnt bar = VBarAnt.create()
    .top(title)
    .center(content)
    .bottom(footer)
    .gap(16)
    .borderRight(false)
    .build();
```

### 4.5 弹性占位用 Spacers

```java
import org.openkawu.jfxium.core.util.Spacers;

// 弹性占位（HBox 推两端）
HBox row = HBoxAnt.create()
    .align(Pos.CENTER_LEFT)
    .children(forgot, Spacers.grow(), register);

// 固定尺寸 spacer
Region gap8 = Spacers.spacer(8, 8);
```

### 4.6 其他布局容器用法

```java
// === StackPaneAnt：徽标覆盖头像 ===
StackPaneAnt avatar = StackPaneAnt.create()
    .align(Pos.TOP_RIGHT)
    .children(avatarImage, badge);

// === FlowPaneAnt：标签云自动换行 ===
```

### 4.7 二维网格：用 `GridAnt`

JFXium 没有 `GridPaneAnt`——二维网格统一用 **`GridAnt`**（24 栅格响应式组件，带 xs/sm/md/lg 断点）：

```java
VBox grid = GridAnt.create()
    .gutter(16)
    .row(GridAnt.row()
        .col(12, formLeft)      // 占 12/24 = 半宽
        .col(12, formRight))
    .build();
```

需要原生 `GridPane` 的场景（如底层自绘容器），属于框架内部实现范畴，业务代码优先 `GridAnt` / `FormAnt`。

## 5. 页面背景色分层

页面不应该整页全白。JFXium 提供四层常用背景色，通过 `Background` 枚举使用。**节点什么都不设时是透明的**（透出父级），需要显式指定才有颜色。

### 5.1 四层速查表

| Background 枚举 | CSS Token | Light 色值 | 用途 | 典型组件 |
|---|---|---|---|---|
| `Background.TRANSPARENT` | `transparent` | `transparent` | 只负责排布，不负责画底色 | `HBoxAnt` / `VBoxAnt` / `HBarAnt` / `VBarAnt` |
| `Background.LAYOUT` | `-color-bg-layout` | `#f0f2f5` | 页面最外层底色（灰底） | AppShell 外围、页面骨架、滚动容器外框 |
| `Background.SUBTLE` | `-color-bg-subtle` | `#f6f8fa` | 次区域底色（Sider、顶部 MenuBar） | Sider、标题条、次级分区、卡片头部 |
| `Background.DEFAULT` | `-color-bg-default` | `#ffffff` | 内容"白卡片"（表单、列表、详情） | 内容区、表单、表格、详情卡片 |

### 5.2 用法

```java
import org.openkawu.jfxium.core.css.Background;

// ---------------- Builder 方式 ----------------
// 页面最外层：LAYOUT
VBoxAnt.create()
    .background(Background.LAYOUT)
    .children(header, content)
    .build();

// 左侧菜单区：SUBTLE
VBoxAnt.create()
    .background(Background.SUBTLE)
    .children(menu)
    .build();

// 内容白卡片：DEFAULT（最常用）
VBoxAnt.create()
    .background(Background.DEFAULT)
    .children(form, table)
    .build();

// ---------------- 原生节点方式 ----------------
import org.openkawu.jfxium.core.css.JfxStyles;

vbox.getStyleClass().add(JfxStyles.BG_LAYOUT);   // → LAYOUT 色
vbox.getStyleClass().add(JfxStyles.BG_SUBTLE);   // → SUBTLE 色
vbox.getStyleClass().add(JfxStyles.BG_DEFAULT);  // → DEFAULT 色
```

### 5.3 典型页面结构

```
┌──────────────────────────────────────────┐
│  AppShell 外围          Background.LAYOUT │  #f0f2f5
│  ┌────────────────────────────────────┐   │
│  │ Header              Background.DEFAULT│ #ffffff
│  ├────────────────────────────────────┤   │
│  │ MenuBar             Background.SUBTLE │ #f6f8fa
│  ├────────┬───────────────────────────┤   │
│  │ Sider  │ Content                   │   │
│  │ SUBTLE │ DEFAULT ← 白卡片           │   │
│  │#f6f8fa │ #ffffff                   │   │
│  ├────────┴───────────────────────────┤   │
│  │ Footer              Background.DEFAULT│ #ffffff
│  └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

> **选择逻辑**：基础布局壳用 `TRANSPARENT`，外围用 `LAYOUT`，侧栏 / 标题条用 `SUBTLE`，内容卡片用 `DEFAULT`。四类色值在各主题下都有独立定义，切主题会自动变色。

### 5.4 一眼记住

| 场景 | 推荐背景 |
|---|---|
| 只是排版，想透出父级底色 | `Background.TRANSPARENT` |
| 页面外层、AppShell、滚动容器外框 | `Background.LAYOUT` |
| 侧栏、标题条、次级分区、轻量头部 | `Background.SUBTLE` |
| 内容主体、表单、列表、详情卡片 | `Background.DEFAULT` |

## 7. 消息与反馈：MessageAnt vs NotificationAnt

JFXium 提供两种反馈通道，**用法区别大**，选错会出现「弹一次就消失」或「点了不响应」。

| 维度 | `MessageAnt` | `NotificationAnt` |
|------|--------------|---------------------|
| **场景** | 操作即时反馈（保存成功 / 失败） | 系统通知（消息中心 / 全局广播） |
| **位置** | 顶部居中（toast） | 右上角（抽屉式堆叠） |
| **交互** | 自动消失（默认 3s） | 可关闭 + 持续显示 |
| **类型** | success / error / warning / info | 同 + 可选标题 / 描述 / 点击回调 |
| **调用方式** | `MessageAnt.success("保存成功")` | 快捷静态：`NotificationAnt.info(title, desc)` 直接弹出；完整链式走 `create()...build().show()` |
| **典型场景** | CRUD 操作反馈 | 新消息提醒 / 系统公告 |

### 7.1 MessageAnt 示例

```java
// 一次性反馈，3 秒后自动消失
MessageAnt.success("保存成功");
MessageAnt.error("保存失败：" + ex.getMessage());
MessageAnt.warning("请检查表单");
MessageAnt.info("正在加载...");
```

### 7.2 NotificationAnt 示例

```java
// 快捷静态方法：直接弹出，无需 build
NotificationAnt.success("保存成功", "用户信息已更新");
NotificationAnt.info("新订单", "您有一笔新订单待处理", 10);   // 10 秒后自动关闭

// 完整链式（带点击回调 + 位置）
NotificationAnt.NotificationResult r = NotificationAnt.create()
    .type(NotificationAnt.Type.SUCCESS)
    .title("新订单")
    .description("您有一笔新订单待处理")
    .onClick(v -> openOrderPage())     // 点击通知体触发
    .duration(5)                       // 自动关闭时长（秒，0 = 不自动关）
    .placement(NotificationAnt.Placement.TOP_RIGHT)
    .closable(true)
    .build();
r.show();
```

### 7.3 选型速记

| 业务场景 | 用哪个 |
|---------|--------|
| CRUD 操作结果（成功/失败）| **MessageAnt** |
| 表单校验错误 | **MessageAnt.error** |
| 异步任务完成 | **MessageAnt.success** |
| 新消息 / 待办提醒 | **NotificationAnt** |
| 系统公告 / 全局广播 | **NotificationAnt** |
| 需要用户后续操作的反馈 | **NotificationAnt**（带 onClick 点击回调） |

## 8. Controller 模式（运行时状态变更）

> 适用于「build() 后需要修改状态」的组件（MenuAnt / StepsAnt / AnchorAnt / TabsAnt / CalendarAnt / PaginationAnt / WatermarkAnt 等）。
> 获取方式有两种：**静态 `XxxAnt.controllerOf(node)`**（MenuAnt / WatermarkAnt / PaginationAnt 等）或 **Builder 的 `controller()` 方法**（StepsAnt / AnchorAnt，必须在 `build()` 之后调用）。目的都是**避免重建整个组件树**。

### 8.1 三类 Controller 用法

```java
// === MenuAnt：动态切换选中项（controllerOf 静态获取）===
Pane menu = MenuAnt.create()
    .item("dashboard", "首页", () -> router.go("dashboard"))
    .subMenu("user", "用户管理")
        .item("user.list", "列表", () -> router.go("user.list"))
        .item("user.add", "新增", () -> router.go("user.add"))
        .endSubMenu()
    .selectedKey("dashboard")
    .build();

MenuAnt.Controller ctrl = MenuAnt.controllerOf(menu);
ctrl.setSelectedKey("user.list");            // 切换高亮
ctrl.setCollapsed(true);                     // 折叠 / 展开侧边菜单
ctrl.setExpandedKeys(java.util.Set.of("user")); // 控制展开的子菜单

// === StepsAnt：推进 / 回退步骤（Builder.controller()，build() 后调用）===
StepsAnt.Builder stepsBuilder = StepsAnt.create()
    .step("基本信息")
    .step("权限设置")
    .step("完成")
    .current(0);
Node steps = stepsBuilder.build();

StepsAnt.Controller sctrl = stepsBuilder.controller();
sctrl.next();                        // current: 0 → 1
sctrl.prev();                        // current: 1 → 0
sctrl.setCurrent(2);                 // 直接跳

// === AnchorAnt：切换激活锚点（Builder.controller()）===
AnchorAnt.Builder anchorBuilder = AnchorAnt.create()
    .item("intro",   "概述", "#intro")
    .item("detail",  "详情", "#detail")
    .item("comment", "评论", "#comment");
VBox anchor = anchorBuilder.build();

AnchorAnt.Controller actrl = anchorBuilder.controller();
actrl.setActiveKey("detail");        // 高亮指定锚点
String active = actrl.getActiveKey();
```

### 8.2 自定义 Controller

```java
// 你的组件暴露 controller() 方法 + 内部静态 Controller 类
public class MyComponentAnt {
    public static class Controller {
        private final MyComponentAnt instance;
        Controller(MyComponentAnt instance) { this.instance = instance; }
        public void setState(State s) { instance.state = s; instance.rebuild(); }
        // ...
    }

    public Controller controller() { return new Controller(this); }
    public static Controller controllerOf(MyComponentAnt c) { return c.controller(); }
}
```

## 9. 跨模块通信用 EventBus + record

> JFXium 提供轻量 `EventBus`（`org.openkawu.jfxium.core.util.EventBus`），用于跨 Stage / 跨模块通信场景。

### 9.1 事件用 record 定义

```java
// ✅ 推荐：record 定义事件——不可变、自动 equals/toString、定义只要 1 行
public record UserLoggedIn(String username) {}
public record OrderCreated(long orderId, BigDecimal amount) {}

// ❌ 反模式：通用 Event<T> 信封类——丢失类型安全 + 字符串路由
public record Event<T>(String type, T data) {}
bus.publish(new Event<>("user.login", "alice"));   // 订阅者拿到的是 Object，要强转
```

### 9.2 需要"统一标记"时用 sealed interface

```java
public sealed interface AppEvent
        permits UserLoggedIn, UserLoggedOut, OrderCreated {
    default long timestamp() { return System.currentTimeMillis(); }
}

public record UserLoggedIn(String username) implements AppEvent {}
public record UserLoggedOut(String username) implements AppEvent {}
public record OrderCreated(long orderId, BigDecimal amount) implements AppEvent {}
```

### 9.3 订阅 + 发布

```java
import org.openkawu.jfxium.core.util.EventBus;
import org.openkawu.jfxium.core.util.EventBus.Subscription;

EventBus bus = EventBus.getDefault();

// 订阅，保存 Subscription 句柄用于取消
Subscription sub = bus.subscribe(UserLoggedIn.class, e -> {
    // 注意：不在 FX Thread——UI 操作要 runLater
    Platform.runLater(() -> welcomeLabel.setText("欢迎，" + e.username()));
});

// 发布（任意线程）
bus.publish(new UserLoggedIn("alice"));

// 不再需要时取消订阅，防止内存泄漏
sub.unsubscribe();
```

### 9.4 典型场景

| 场景 | 发布方 → 订阅方 |
|---|---|
| 登录成功通知主窗口刷新 | `LoginStage` → `MainStage` |
| 后台任务结果上报 | worker 线程 → UI 多模块 |
| 配置变更广播 | `SettingsDialog` → 各业务页 |
| 数据 CRUD 后通知列表刷新 | `EditDialog` → `TablePage` |

### 9.5 避免误用

- ❌ 不要用 EventBus 做「请求-响应」（RPC 场景用 `CompletableFuture` 或接口注入）
- ❌ 不要订阅 `AppEvent.class` 期望收到所有子类事件 —— 本框架是**精确类型匹配**
- ❌ 不要忘记 `unsubscribe()` —— listener 会持有外部引用，导致 GC 失败

## 11. 公共规范速记

| 类别 | 规范 |
|------|------|
| **样式入口** | 所有颜色 / 字号 / 边框走 `styleClass` + LESS，绝不 `setStyle()` |
| **styleClass 前缀** | 新增必须 `jfx-` 前缀（如 `jfx-my-component`）|
| **返回类型** | 持久节点直接返回 Node；弹窗返回 Result wrapper（`.open(trigger)` 才显示）|
| **可选回调** | `null` 即不绑 handler，不调即不渲染 |
| **build() 幂等** | 重复调用不累积 spacer / listener / 临时子节点 |
| **i18n** | 字段初始化为 `null`，build() 中懒解析；持久组件监听 `localeProperty()` |
| **FX 线程** | snapshot() / Canvas / scene-graph 操作前 `Platform.isFxApplicationThread()` 检查 |
| **模块导出** | 新增 public 类必同步 `module-info.java` exports |
| **禁止原生控件** | 业务代码 `new Label/Button/...` 一律走 `XxxAnt.create(...)` |
