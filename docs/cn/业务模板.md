# JFXium 业务模板

> M18 起，JFXium 把"针对业务场景的整页骨架"独立到 `jfxium/template/` 包，命名后缀 `*Template`。
> 与 `*Ant` 区别：`*Ant` 是原子控件可自由组合，`*Template` 是整页骨架装载多个原子控件 —— admin 后台 90% 业务页直接用模板替代手写。

## 模板全景（11 个）

| 模板 | 结构 | 适用场景 | 关键 API |
|------|------|---------|---------|
| **PageTemplate** | title + desc + body | 展示页 / 文档 / 设置 / 任何简单内容页 | `title()` / `description()` / `body()` / `section()` / `sections()` |
| **CrudTemplate** | title + topbar + body + bottombar | 列表 / 表单 / 详情 / 仪表盘（带工具栏）| `topLeft()` / `topRight()` / `bottomLeft()` / `bottomRight()` |
| **DashboardTemplate** | welcome + 统计卡矩阵 + 双栏底部 | 数据概览首页 | `welcome()` / `stat()` / `bottomLeft()` / `bottomRight()` |
| **LoginTemplate** | banner + 表单 | 登录 / 注册 | `brandName()` / `onSubmit()` / `onForgot()` / `onRegister()` |
| **WorkspaceTemplate** | brand + header + sider + content + footer | 后台壳 / 工作台 / 需要 sider 的生产系统 | `brand()` / `sider()` / `content()` / `collapsible()` / `breakpoint()` |
| **FilterBarAnt** | 左筛选 + 右操作 | admin 列表页顶部筛选工具条 | `search()` / `filter()` / `action()` / `actionPrimary()` |
| **LaunchPadTemplate** | 标题 + N 列卡片网格 | 工作台首页 / 控制台首页快捷入口 | `item()` / `columns()` / `onAction()` |
| **ShowcaseSectionTemplate** | 小标题 + 说明 + 演示区 | 示例页 / 文档页 section | `title()` / `description()` / `body()` |
| **WorkspaceSettingsTemplate** | 主题 + 密度 + 主色 + 水印设置 | 工作台外观设置抽屉 | `themeManager()` / `watermarkVisibleSupplier()` |
| **ProjectShowcaseTemplate** | 工程项目首页 | JFXium 自展示 / 项目门面 | `hero()` / `section()` |
| **ProjectQuickStartTemplate** | 步骤条 + 代码片段 | Getting Started / 接入指南 | `step(title, desc)` / `step(title, desc, code, language)` |

> Project\* 系列（Feature / Overview / Changelog / Release / Hero / Dashboard / Console）是 `ProjectShowcaseTemplate` 的子组件，专门用于「项目自展示」场景，本文档不展开，详见源码 `jfxium/template/` 包与 Showcase Demo「工程展示」分类。

## 模板边界对照

| 想做的页面 | 用哪个 |
|---|---|
| 简单展示页 / 文档 / 设置 / showcase 页 | **PageTemplate**（最简，只有大标题 + 描述 + 内容）|
| 列表 / 表单 / 详情 / 仪表盘（带工具栏） | **CrudTemplate** |
| 数据概览首页（统计卡 + 多区） | **DashboardTemplate** |
| 登录 / 注册（双栏 banner）| **LoginTemplate** |
| 后台壳 / 需要 sider + 折叠的生产系统 | **WorkspaceTemplate** |
| admin 列表页顶部筛选工具条 | **FilterBarAnt**（搜索 + 筛选 + 操作按钮标准化拼装） |
| 工作台首页快捷入口（标题 + 卡片网格） | **LaunchPadTemplate** |
| 工作台外观设置面板 | **WorkspaceSettingsTemplate**（或直接 `.drawer(...)` 一行） |

## PageTemplate 详细说明

PageTemplate 是最简的展示页骨架——「大标题 + 描述 + 内容区」三层结构。**适合所有不需要 topbar/bottombar 的简单内容页**。它直接替代了 admin / showcase 项目里到处重复的下面这段样板代码：

```java
// ❌ 改造前：每个 page 都要手写 header + body 的 5 行样板代码
LabelAnt pageTitle = LabelAnt.create("Button 按钮").build();
LabelAnt pageDesc  = LabelAnt.create("最常用的交互组件...").secondary().build();
VBoxAnt header = VBoxAnt.create().spacing(8).children(pageTitle, pageDesc).build();
return VBoxAnt.create()
        .spacing(20)
        .children(header, sectionA(), sectionB(), sectionC())
        .build();

// ✅ 改造后：一行定义，样式 / 间距 / 背景 全部走 styleClass + LESS
return PageTemplate.create()
        .title("Button 按钮")
        .description("最常用的交互组件...")
        .sections(sectionA(), sectionB(), sectionC())
        .build();
```

**多种用法**：

```java
// 1. Showcase 页（多 section 竖排）
VBox page = PageTemplate.create()
    .title("Button 按钮")
    .description("可点击的交互元素，支持多种 type / size / shape")
    .section(buildBasicSection())
    .section(buildSizeSection())
    .section(buildShapeSection())
    .build();

// 2. 设置页（单一 body 节点）
VBox page = PageTemplate.create()
    .title("应用设置")
    .description("配置主题、语言、快捷键等偏好")
    .body(settingsForm)
    .build();

// 3. 极简（仅标题 + body，无描述）
VBox page = PageTemplate.create()
    .title("欢迎")
    .body(welcomeContent)
    .build();

// 4. 文档页（仅标题 + 描述，不带 body）
VBox doc = PageTemplate.create()
    .title("使用说明")
    .description("本系统支持以下操作...")
    .build();
```

**装饰参数**（按需调整）：

```java
PageTemplate.create()
    .title("...")
    .description("...")
    .sections(...)
    .headerGap(8)         // title ↔ description 间距（默认 8）
    .sectionGap(20)       // section 之间间距（默认 20）
    .headerToBodyGap(20)  // header → body 间距（默认 20）
    .padding(24)          // 整体 padding（默认 0，让父容器决定）
    .background(Background.DEFAULT)  // 整体背景层级（默认白底）
    .build();
```

> **设计要点**：
> - 视觉样式 100% 走 styleClass + LESS（`.jfx-page-template-title` / `.jfx-page-template-desc`），符合 SKILL #1 强约束
> - title / description / body 全部可选——不调用就不渲染
> - 底层是 VBox（不是 BorderPane），高度自适应内容

## CrudTemplate 详细说明

CrudTemplate 不只适用 CRUD —— **任何「上工具栏 + 中间主内容 + 下分页/状态栏」形态都能用**：表单页 / 详情页 / 仪表盘 / 极简内容页。

```java
// 列表页（最经典）
BorderPane page = CrudTemplate.create()
    .title("用户管理")
    .topLeft(searchField, roleCombo, statusCombo)   // 左：筛选
    .topRight(refreshBtn, addBtn)                   // 右：操作
    .body(table)                                    // 中：表格
    .bottomLeft(totalLabel)                         // 左：总条数
    .bottomRight(pagination, pageSizeCombo)         // 右：分页
    .bordered(true)
    .build();

// 表单页（仅 body + 底部右侧提交）
BorderPane form = CrudTemplate.create()
    .title("新增用户")
    .body(formContent)
    .bottomRight(cancelBtn, submitBtn)
    .build();

// 仪表盘（顶部刷新+导出 + body 是统计卡矩阵）
BorderPane dash = CrudTemplate.create()
    .title("数据概览")
    .topRight(refreshBtn, exportBtn)
    .body(statsGrid)
    .build();
```

> 内部 topbar/bottombar 用 HBarAnt 拼装（`HBarAnt.create().left().right()`），无需手动 spacer。

## LoginTemplate 详细说明

```java
BorderPane login = LoginTemplate.create()
    .brandName("My Admin")                                    // 品牌名（默认走 i18n）
    .tagline("企业管理系统")                                    // 品牌标语（可选）
    .features("全量组件/模板参考", "11 套主题入口", "Builder API") // 卖点列表
    .copyright("© 2026 · MIT License")                         // 底部版权（默认走 i18n）
    .bannerWidth(360)                                          // 左 banner 宽度（默认 360）
    .formTitle("欢迎回来")                                     // 表单标题（默认走 i18n）
    .formSubtitle("请输入账号密码登录")                          // 表单副标题（可选）
    .usernamePlaceholder("账号")                               // 用户名占位符
    .passwordPlaceholder("密码")                               // 密码占位符
    .submitText("立即登录")                                    // 按钮文案
    .showRememberMe(true)                                      // 是否显示「记住我」
    .onSubmit((username, password) -> auth(username, password)) // 登录回调
    .onForgot(() -> openForgotPwd())        // 不调即不显示链接
    .onRegister(() -> openRegister())       // 不调即不显示注册区
    .build();

Scene scene = new Scene(login, 760, 520);
stage.setScene(scene);
stage.show();
```

> **i18n 懒解析**：所有文案字段 `null` 时走 `Messages.get(...)` 默认值（zh_CN），避免锁死 Locale。

## DashboardTemplate 详细说明

```java
VBox dashboard = DashboardTemplate.create()
    .welcome("欢迎回来，张三 👋")
    .stat(IconAnt.Path.USERS,    "总用户",   "1,234",   "↑ 12.5%", true)   // up=true 绿色
    .stat(IconAnt.Path.FILE,     "今日订单", "89",      "↓ 3.2%",  false)  // up=false 红色
    .stat(IconAnt.Path.CHART,    "月销售额", "¥125k",   "↑ 8.4%",  true)
    .stat(IconAnt.Path.DASHBOARD,"转化率",   "23.4%",   "↑ 1.2%",  true)
    .statColumns(4)              // 强制 4 列（默认按 stat 数量自动）
    .bottomLeft(activityCard)   // 占 60%
    .bottomRight(todoCard)      // 占 40%
    .leftRatio(60)              // 可调比例（[10,90]）
    .sectionGap(20)             // 欢迎/统计/底部 间距
    .padding(24)                // 整体 padding
    .build();
```

> 统计卡内部用 `GroupBoxAnt + 图标盒 + 标题 + 大值 + 趋势文字`，与展示页风格一致。

## WorkspaceTemplate 详细说明

WorkspaceTemplate 是基于 `AppShellAnt` 的高阶工作台壳模板——把 header 编排成「品牌 + 导航 + 操作区」工作台样子，并继承 AppShell 的 sider 折叠 / 响应式断点能力。

```java
BorderPane shell = WorkspaceTemplate.create()
    .brand("JFXium Workspace", "高可用工作台")     // 品牌标题 + 副标题
    .brandIcon(IconAnt.Path.DASHBOARD)             // 品牌图标（自动包 AvatarAnt）
    .headerTop(menuBar)                            // 顶栏（系统菜单 / 通知条）
    .headerCenter(breadcrumb)                      // 中间（Breadcrumb / Tabs）
    .headerRight(refreshBtn, collapseBtn, userMenu)// 右侧操作
    .sider(navMenu, 240)                           // 侧栏 + 宽度
    .content(mainPage)                             // 主内容
    .footer(statusBar)                             // 底栏
    .collapsible(true)                             // 启用侧栏折叠
    .collapsed(false)                              // 初始展开
    .collapsedWidth(64)                            // 折叠后宽度
    .breakpoint(GridAnt.Breakpoint.LG)             // 响应式断点
    .siderBackground(Background.SUBTLE)            // 侧栏背景层级
    .contentBackground(Background.DEFAULT)         // 内容背景层级
    .build();
```

**折叠控制**（保留 AppShell 能力）：

```java
WorkspaceTemplate.Result result = WorkspaceTemplate.create()
    .sider(nav).collapsible(true).buildResult();
result.setCollapsed(true);              // 收起
result.toggle();                        // 切换
boolean collapsed = result.isCollapsed();
BooleanProperty prop = result.collapsedProperty();  // 双向绑定
```

**一键头像下拉菜单**：

```java
// userMenu 返回 DropdownResult；取 getTrigger() 拿到「头像 + 用户名」触发节点放进 headerRight
Node userMenu = WorkspaceTemplate.userMenu("张三", key -> {
    switch (key) {
        case "settings" -> openSettings();
        case "about"    -> showAbout();
        case "logout"   -> logout();
    }
}).getTrigger();

// 放入工作台头部右侧
WorkspaceTemplate.create()
    .headerRight(refreshBtn, collapseBtn, userMenu)
    ...
```

> 内置「外观设置 / 关于 / 退出」三项；点击触发节点自动弹出下拉。

## FilterBarAnt 详细说明

admin 列表页顶部筛选工具条——左筛选 + 右操作，用 Region spacer 弹性分隔。

```java
HBox bar = FilterBarAnt.create()
    .search("搜索用户名/邮箱", 240, kw -> reload(kw))   // 搜索框（带回车回调）
    .filter("角色", roleCombo)                           // 带 label 前缀
    .filter("状态", statusCombo)                         // 任意 Node + label
    .filter(datePicker)                                 // 无 label 版本
    .action("刷新", () -> reload())                     // DEFAULT 按钮
    .actionPrimary("新增", "+", () -> openAddModal())   // PRIMARY 按钮 + 前缀字符
    .spacing(12)
    .padding(8, 16, 8, 16)
    .build();
```

> 通常配合 `CrudTemplate.topLeft(FilterBarAnt.create()....build())` 使用。

## LaunchPadTemplate 详细说明

首页 / 控制台快捷入口模板——「标题 + 说明 + N 列卡片网格」。

```java
VBox launchpad = LaunchPadTemplate.create()
    .title("快捷入口")
    .description("把最常用的页面和模板摆在首页")
    .columns(3)                                          // 列数（默认 2）
    .gap(16)                                             // 卡片间距
    .item("user-mgmt",   "用户管理", "管理账号与权限",  IconAnt.Path.USERS)
    .item("order-mgmt",  "订单管理", "查看与处理订单",  IconAnt.Path.FILE)
    .item("dashboards",  "数据概览", "实时业务指标",    IconAnt.Path.CHART)
    .onAction(key -> router.navigate(key))
    .build();
```

## WorkspaceSettingsTemplate 详细说明

工作台外观设置抽屉内容——主题家族、明暗模式、密度、主色、水印。

```java
// 水印可见性由业务侧自己持有状态（WatermarkAnt 无全局静态开关）
BooleanProperty watermarkVisible = new SimpleBooleanProperty(true);

// 方式一：一行构建抽屉（推荐）
DrawerAnt.DrawerResult drawer = WorkspaceSettingsTemplate.drawer(
    () -> watermarkVisible.get(),       // 当前水印可见性 Supplier
    v -> watermarkVisible.set(v)        // 水印变更回调（业务侧负责挂/摘水印）
);
drawer.open(trigger);
// 另有 drawer(int width, Supplier, Consumer) 重载可指定抽屉宽度

// 方式二：直接拿到内部 VBox，自定义弹窗容器
VBox settingsBody = WorkspaceSettingsTemplate.create()
    .title("外观设置")
    .description("切换主题、密度、主色和全局水印")
    .themeManager(ThemeManager.getInstance())  // 可注入自定义管理器（默认全局单例）
    .watermarkVisibleSupplier(() -> watermarkVisible.get())
    .onWatermarkVisibleChanged(v -> watermarkVisible.set(v))
    .build();
```

## 通用规范

所有 Template 共用以下规范：

1. **视觉样式 100% 走 styleClass + LESS**——禁止 inline `setStyle()` 写颜色 / 字号 / 边框
2. **i18n 懒解析**——所有文案字段 `null` 时走 `Messages.get(...)` 默认 zh_CN，监听 `Messages.localeProperty()` 实时切换
3. **`build()` 返回类型诚实**——持久显示节点（VBox / BorderPane / HBox）直接返回节点；on-demand 弹窗（Drawer / Modal）返回 Result wrapper，调用 `.open(trigger)` 显示
4. **可选回调 / 可选节点不调即不渲染**——所有回调（`onSubmit` / `onForgot`）和可选节点（`brandName` / `tagline` / `welcome`）都遵循「null 即跳过」
5. **数值参数防御**——`gap` / `padding` / `width` 等数值走 `TextUtils.safeNonNegative` / `safePositive`，NaN / 负数自动钳到安全值
6. **依赖 `AppShellAnt` 等已有基础设施**——WorkspaceTemplate 等高阶模板不重复造轮子，直接复用 AppShell 的折叠 / 响应式
